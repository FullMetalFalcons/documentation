## About This Repository

This documentation is organized by **robotics discipline** — Programming, Building, Engineering, and Outreach — so it can serve as a durable knowledge base that grows with the team year over year. Topics that span multiple disciplines (like drive systems) live in a shared location and are referenced from each relevant section. Season-specific details (game rules, match strategies, team rosters) belong in each season's dedicated team repository.

## Contributing

If you find something outdated or want to add new content, open a pull request! Follow the existing folder structure and link related topics across sections using cross-references.
