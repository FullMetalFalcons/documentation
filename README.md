## About This Repository

This documentation is organized by **robotics engineering discipline** rather than by season, so it can serve as a durable knowledge base that grows with the team year over year. Season-specific details (game rules, match strategies, team rosters) belong in each season's dedicated team repository.

## Contributing

If you find something outdated or want to add new content, open a pull request! Follow the existing folder structure and link related topics across sections using cross-references.
